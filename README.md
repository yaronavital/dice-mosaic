# Dice Mosaic

Turn any photo into a mosaic made of dice. Choose a resolution from 1 to 1,000,000 dice, using white dice, black dice, or both, and get the exact number of each face you need. Then print a section-by-section build plan to make it at home.

Use it: https://yaronavital.github.io/dice-mosaic/

Everything runs in your browser. Your photo is never uploaded anywhere.
